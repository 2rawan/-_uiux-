# إضافة Forma إلى Figma

تنشئ هذه الإضافة نموذجًا أوليًا قابلًا للتحرير من ملف `forma-design.json`: لكل شاشة إطار سطح مكتب وإطار هاتف، وتتحول الأزرار وروابط الأقسام ودليل الشاشات إلى روابط تنقّل داخل النموذج. العناصر طبقات Figma أصلية (نصوص وأشكال وإطارات)، وليست صورًا مسطّحة.

## تجهيز ملف التصميم

من جذر المشروع شغّلي:

```sh
npx tsx scripts/export-design.ts
```

يُنشأ الملف `public/design/forma-design.json`. يعرضه تطبيق الويب عبر خادم التطوير على `http://localhost:3000/design/forma-design.json`، أو يمكن اختيار الملف مباشرةً من القرص في الإضافة. ملف JSON مخصص لهذه الإضافة؛ **لا يُستورد من قائمة File في Figma كأنه ملف تصميم أصلي**.

## تشغيل الإضافة محليًا

1. افتحي تطبيق Figma لسطح المكتب، ثم من قائمة Figma اختاري **Plugins → Development → Import plugin from manifest…**.
2. اختاري `figma-plugin/manifest.json` من هذا المشروع. يتطلب ذلك تفعيل أدوات التطوير/الإضافات المحلية في Figma.
3. شغّلي **Plugins → Development → Forma editable prototype importer**.
4. اختاري `public/design/forma-design.json` واضغطي **إنشاء النموذج التفاعلي**.
5. افتحي صفحة `Forma · Editable prototype`. نقطة البداية هي أول شاشة على سطح المكتب؛ زر «دليل كل الشاشات» يتيح الوصول إلى أي شاشة، كما تتصل الأزرار الأخرى بأهدافها المحددة.

إذا تعذر استخدام إضافة التطوير، جرّبي النموذج التفاعلي في الموقع عبر `npm run dev` ثم افتحي `http://localhost:3000`. معاينة الموقع بديل للتجربة، لكنها لا تحوّل JSON إلى طبقات Figma.

## محتوى النموذج

ينشئ الملف إطارين لكل شاشة من الكتالوج، بالإضافة إلى دليلي شاشات (سطح المكتب والهاتف). يتعرف المستورد على بطاقات الإحصاءات، النماذج وحقولها، الجداول وصفوفها، مساحات المكتب، الاجتماعات، التفاصيل، وحالات الفراغ والنجاح. تُتحقق بنية الملف ومعرّفات الشاشات وأهداف الروابط قبل الإنشاء؛ وعند حدوث خطأ أثناء الإنشاء تُحذف صفحة Forma الجزئية بدل ترك تصميم ناقص.

تُنشأ الطبقات داخل صفحة مستقلة باسم `Forma · Editable prototype`؛ لا تُستبدل صفحات الملف الموجودة. لا تستخدم الإضافة الشبكة ولا ترفع الملف إلى خدمة خارجية. بيانات الشاشات تجريبية وليست بيانات إنتاجية.
