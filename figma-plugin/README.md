# إضافة Forma إلى Figma

تنشئ هذه الإضافة نموذجًا أوليًا قابلًا للتحرير من ملف `forma-design.json`: لكل شاشة إطار سطح مكتب وإطار هاتف، وتتحول الأزرار وروابط الأقسام ودليل الشاشات إلى روابط تنقّل داخل النموذج. العناصر طبقات Figma أصلية (نصوص وأشكال وإطارات)، وليست صورًا مسطّحة.

## تجهيز ملف التصميم

من جذر المشروع شغّلي:

```sh
npx tsx scripts/export-design.ts
```

يُنشأ الملف `public/design/forma-design.json`. يعرضه تطبيق الويب عبر خادم التطوير على `http://localhost:3000/design/forma-design.json`، أو يمكن اختيار الملف مباشرةً من القرص في الإضافة. ملف JSON مخصص لهذه الإضافة؛ **لا يُستورد من قائمة File في Figma كأنه ملف تصميم أصلي**.

## تشغيل الإضافة محليًا

1. افتحي تطبيق Figma لسطح المكتب، ثم اختاري **Plugins → Development → New Plugin…** وأنشئي إضافة **Figma Design** محلية. Figma يولّد لها معرّف الإضافة (`id`) الخاص بك.
2. انسخي قيمة `id` من manifest الذي ولّده Figma إلى `figma-plugin/manifest.json`، مع الإبقاء على `main`, `ui` وبقية القيم الموجودة. لا تستخدمي معرّفًا تجريبيًا أو معرّف شخص آخر؛ Figma يعيّن المعرّف وهو مطلوب في تعريف الإضافة. احتفظي به في مشروعك عند إعادة الاستيراد.
3. من **Plugins → Development → Import plugin from manifest…** اختاري `figma-plugin/manifest.json`. يتطلب ذلك تفعيل أدوات التطوير/الإضافات المحلية في Figma.
4. شغّلي **Plugins → Development → Forma editable prototype importer**.
5. اختاري `public/design/forma-design.json` واضغطي **إنشاء النموذج التفاعلي**.
6. افتحي صفحة `Forma · Editable prototype`. نقطة البداية هي أول شاشة على سطح المكتب؛ زر «دليل كل الشاشات» يتيح الوصول إلى أي شاشة، كما تتصل الأزرار الأخرى بأهدافها المحددة.

إذا تعذر استخدام إضافة التطوير، جرّبي النموذج التفاعلي في الموقع عبر `npm run dev` ثم افتحي `http://localhost:3000`. معاينة الموقع بديل للتجربة، لكنها لا تحوّل JSON إلى طبقات Figma.

## محتوى النموذج

ينشئ الملف إطارين لكل شاشة من الكتالوج، بالإضافة إلى دليلي شاشات (سطح المكتب والهاتف). إطارات الشاشات قابلة للتمرير عموديًا حتى لا تُقص إجراءات الشاشة الطويلة، ودليل الهاتف قابل للتمرير للوصول إلى كل البطاقات. يتعرف المستورد على بطاقات الإحصاءات، النماذج وحقولها، الجداول وصفوفها، مساحات المكتب، الاجتماعات، التفاصيل، وحالات الفراغ والنجاح. تُتحقق بنية الملف ومعرّفات الشاشات وأهداف الروابط قبل الإنشاء؛ وعند حدوث خطأ أثناء الإنشاء تُحذف صفحة Forma الجزئية بدل ترك تصميم ناقص.

تُنشأ الطبقات داخل صفحة مستقلة باسم `Forma · Editable prototype`؛ لا تُستبدل صفحات الملف الموجودة. لا تستخدم الإضافة الشبكة ولا ترفع الملف إلى خدمة خارجية. بيانات الشاشات تجريبية وليست بيانات إنتاجية.

`networkAccess.allowedDomains` مضبوط على `none`. لا يحتوي المستودع معرّف Figma صالحًا مسبقًا؛ إضافة معرّف مصنوع قد تمنع الاستيراد أو تربط عمليات نشر لاحقة بمعرّف غير مملوك لك، لذلك خذي المعرّف الحقيقي من خطوة **New Plugin** أعلاه قبل استيراد manifest.
